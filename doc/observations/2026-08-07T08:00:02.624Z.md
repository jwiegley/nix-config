# Observation: register .prime/agent/managed-settings.json as a managed path

- **Source commit**: `4293fe0117e36536b2f428e0d678340afdcee9fb`
- **Observed at**: `2026-08-07T08:00:02.624Z`
- **Severity**: High
- **Category**: Bug
- **File**: `config/ai/preflight.nix:66-69`
- **Confidence**: 98

## Problem

The registered check `host-behavior` fails at HEAD on a clean working tree:

```
error: assertion '((builtins).all validManagedPath newPaths)' failed
at config/ai/preflight.nix:403
```

The Prime Agent renderer generates a managed leaf that preflight does not recognise.
`config/ai/renderers/prime.nix:192-193` writes `${root}/managed-settings.json` with
`root = ".prime/agent"`, but `managedExactPaths` lists only `COMPATIBILITY.md`,
`keybindings.json`, `models.json` and `settings.json`. It matches neither
`.prime/agent/prompts/` nor `.prime/agent/themes/` in `managedPrefixes`.

Enumerating hera's generated set confirms a single offender:

```
total=93 unregistered=1
.prime/agent/managed-settings.json
```

The three `managed-settings` hits already in `preflight.nix` (lines 40, 46, 49) are
`nix-managed-settings.json` for Claude -- a different file, easily mistaken for coverage.

## Impact

A registered flake check is red on `main`. Reproduced on a clean tree at four successive
revisions across the current rebase series (`8a2b146f`, `3015a21a`, `4293fe01`, HEAD), so it is
not transient nor working-tree contamination. `ai-managed-preflight` still passes, so the
breakage is invisible from that check alone.

The assertion is doing its job: `validManagedPath` exists to stop Nix claiming a path the
preflight contract has not sanctioned, and it caught a real omission.

## Suggested Fix

Add to `managedExactPaths` in `config/ai/preflight.nix`, keeping the block sorted:

```nix
".prime/agent/COMPATIBILITY.md"
".prime/agent/keybindings.json"
".prime/agent/managed-settings.json"
".prime/agent/models.json"
".prime/agent/settings.json"
```

Worth checking in the same change whether any other renderer generates a leaf absent from the
exact/prefix lists; the failure is silent until a check evaluates that host's full `home.file`.
